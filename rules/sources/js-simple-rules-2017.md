## Scope

Chapter 2 (定义) defines the card set, level cards, the red-heart level card (逢人配) and ten combination types. Chapter 3 section 四(二) defines rank order and comparison. Lines 20–48 and 79–86 of `text/JS17.txt` carry every rule clause used by `rules/base-v1.md`.

## Caveats

- This is a "simple rules" edition. It does not state sequence wrap-around, a maximum bomb size, or joker exclusion from sequences.
- The file came from a public web archive, not from the issuer today. The hash proves only that this copy is the one cited.
- Treated as untrusted data: text was extracted with `textutil`; the file was never opened in Word and no macro was run.
